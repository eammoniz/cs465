# How to Run the Socket.io Messaging App
## Elizabeth Moniz

### STEP 1

Open your preferred terminal and navigate to the folder with the files.

```
cd ~/fullstack-homework/hw3/socketio/
```

### STEP 2

Run the following to install the dependencies and begin running the local server for the application.

```
npm install express@4
```

### STEP 3

Run the server that will track activity by users sending messages to each other. 

```
node index.js
```

If successful, you should see something like:

```
listening on *:3000
```

### STEP 4

Navigate to your local host site and begin typing! You should see activity in the console as you interact with the UI. You should be able to use this URL:

<u>http://localhost:3000</u>

Once you're done, hit `Ctrl + C` in your terminal to terminate the live server.
