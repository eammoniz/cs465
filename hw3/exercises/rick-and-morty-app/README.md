# How to Run the Rick and Morty App Site
## Elizabeth Moniz

### STEP 1

Open your preferred terminal and navigate to the folder with the files.

```
cd ~/fullstack-homework/hw3/exercises/rick-and-morty-app/
```

### STEP 2

Run the following to install the dependencies and begin running the local server for the application.

```
npm install
npm run dev
```

Navigate to the local host server URL provided by the VITE application. It may be:

<u>http://localhost:5173/</u>

Click between tabs to view information about the show!
Once you're done, hit `Ctrl + C` in your terminal to terminate the server.
