# How to Run Tic-Tac-Toe
## Elizabeth Moniz

### STEP 1

Open your preferred terminal and find the "react" folder.

```
cd ~/fullstack-homework/hw3/react/corrections/
```

### STEP 2

Run the following to install the dependancies and begin running the local server for the application.

```
npm install
npm start
```

Navigate to the local host server with this URL in your browser of choice

<u>http://localhost:3000</u>

Have fun!
Once you're done, hit `Ctrl + C` in your terminal to terminate the server.
